# NORTH STAR（如果忘记一切，记住这个）

一个未来文明解决了所有可以计算的问题。

一个年轻档案员发现了一个无法被系统解释的词：**AGAPE**。

他回到地球寻找它的意义。

他通过废墟、遗忘的人、选择、失败、牺牲、失去、宽恕、希望、重建，发现了圣经。

他开始问：**"他们相信什么？"**

最终变成：**"这对我意味着什么？"**

在一切之下：**WHAT IS AGAPE?**

---

# 世界背景（已锁定）

## 未来社会
- 几百年后，人类离开地球，住在太空殖民地
- 科技解决了：疾病、衰老、贫穷、资源分配
- 文明高度运作，**不是崩溃的反乌托邦**

## 人类失去了什么
- 信仰不是被消灭的——它是被**优化掉**的
- 牺牲变得难以合理化
- 无条件的爱变得难以建模
- 文明格言：**"优化即纯洁。情感即低效。"**

## 真正的冲突
```
计算 vs 意义
```
科技不是恶的。它只是无法回答所有人类的问题。

# PLAYER MOVEMENT / IMMERSION — FUTURE DIRECTION

当前 Chapter 1 叙事不锁死 click-to-move。

未来优先评估的 movement direction：

> **Invisible analog movement + contextual character/environment response**

目标不是把 Bible Explorer 变成 action game，而是让玩家更像“亲自走进 Eden”。

可能包含：
- natural acceleration / deceleration
- idle / walk / facing states
- optional faster walk；run 非必要
- ruin dust footsteps
- living-Eden grass displacement
- surface-specific footsteps
- subtle head-turn toward important discoveries
- contextual slowdown / camera framing near major reveals

叙事层必须保持 input-agnostic：

> Story beats react to **player position + world state**, not to the specific control method used to reach that position.

因此：
- Tablet detection 继续以 proximity / state 为核心
- scanner / persistence / story progression 不应依赖 mouse click 事件
- 未来从 click/tap 改成 analog / virtual joystick / controller 时，不应要求重写 Chapter 1 storyline
- movement animation 与环境脚步效果属于 presentation / locomotion system，不属于 narrative gate

**Implementation status:** PARKED / NOT AUTHORIZED DURING M04-VS1.

## M04 叙事核心

六块 Creation Tablets 是 Eden 记忆的隐藏语法。

它们不是 collectible，不是六个任务，不是六次强制读经。

Genesis 的三个问题层：

- Genesis 1 fragments：**这里如何被创造？**
- Genesis 2：**这里原本是什么？**
- Genesis 3：**这里发生了什么？**

五个旧环境线索继续存在，但被整合为 Tablets I–V 周围的 **environmental evidence regions**。环境证据与 tablet correlation 共同形成 discovery beat，而不是额外制造扫描清单。

## Authority boundary

**Storyline Master owns：**
- ARCHIVIST dialogue
- scanner wording
- Scripture fragment semantic anchor
- narrative beat / pacing

**Visual Master owns：**
- tablet physical appearance
- material / erosion / fracture
- lighting / composition
- visual animation / transition language

Codex 只能使用 neutral placeholders，不能宣布最终 tablet visual。

## Tablet Scripture ranges

| Tablet | Range | Narrative function |
|---|---|---|
| I | Genesis 1:1–5 | Light / separation |
| II | Genesis 1:6–8 | Sky / waters |
| III | Genesis 1:9–13 | Land / vegetation |
| IV | Genesis 1:14–19 | Celestial rhythm |
| V | Genesis 1:20–23 | Aquatic life / birds |
| VI | Genesis 1:24–31 | Animals / humankind |

Fragments 锁定的是语义，不锁死英文译本；最终显示跟随采用的 Bible translation。

Scanner 禁止：
- tablet collected
- 1/6、2/6
- percentage completion
- Creation Day complete
- theology explanation
- quiz
- reward / score
